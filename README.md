# Saisonkalender

Zeigt eine Liste heimischer Lebensmittel in Deutschland, die gerade
saisonal verfügbar sind, gegliedert nach Anbaumethode.

Die Anwendung ist als Progressive Webanwendung implementiert, so dass sie
auch ohne Internetverbindung benutzt werden kann.
Die Daten basieren auf dem Saisonkalender der Verbraucherzentralen in
Deutschland (6. Auflage, November 2022;
[PDF](https://www.verbraucherzentrale.de/sites/default/files/2023-01/vz-saisonkalender.pdf)).

[Link zum Saisonkalender](https://enz.github.io/saisonkalender/)
